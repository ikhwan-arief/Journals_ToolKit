# Pre-assessment report template

Use these headings and fields. Omit empty optional details, but retain the
coverage and limitations sections. Write plain advice to the editor.

## Journal and baseline

- Journal homepage: [URL]
- Date checked: [date]
- Plugin: DOAJ Pre-Assessment Pilot 0.1.0 (independent)
- Criteria: Guide 2.9; application form 3.1 (January 2026);
  Transparency Principles 4.0 (September 2022);
  proposal rulebook 2026.10.0

## What was observed

Summarise the number of required criteria with observed matches, observed
conflicts, and unverifiable results. State how many recommended and
best-practice observations were made. Do not compute an overall readiness
percentage or acceptance probability. Separate observed evidence from
unverified coverage.

## Before you apply

Group actions by the public journal page the editor should review. Put
required items first, then recommendations. For each action show the rule
ID, the specific gap, a rulebook-based suggested correction, and its
official source section. Include a link to the existing page when known.

## Findings

For each relevant rule:

| Field | Content |
| --- | --- |
| Rule and level | ID, title, and required/recommended/principle/record-check label |
| Status | Observed match, Observed conflict, Unverifiable, For DOAJ review, or Not applicable |
| Evidence | Short exact quote in source language; translation if needed |
| Location | Journal or registry URL, PDF page if available, and date accessed |
| Interpretation | What that specific evidence supports and what it cannot establish |
| Action | Suggested correction or check from the packaged criterion map |
| Frozen source | Guide/form/principle section from the packaged baseline |

For a contradiction, show both quotes and locations. An unverifiable
finding names the inaccessible source or incomplete sample. Do not show
an unsupported pass.

## Application form guide

Follow every row of references/form-map.md in v3.1 order. For each field:

- Question or field name and FQ mapping.
- Website-supported answer, or **Not found on the pages inspected**.
- Exact URL to give when the form asks for one, or **No supported URL**.
- What the frozen baseline asks and the linked criterion level.
- Common mistake and a check before the editor answers.

Mark keywords as suggestions. The final accuracy declaration belongs to
the editor; this report does not complete it.

## Pages and records read

List each opened journal page, article HTML/PDF, and public registry record
with URL, access date, and whether the content was readable. List attempted
but unreadable locations separately. State the actual article sample and
any missing issues, PDFs, or language versions. This is an observation log,
not a stored snapshot or a claim of exhaustive crawling.

## Limits and official application

State: This automated, independent pre-assessment is based on the public
pages ChatGPT could inspect against a frozen criteria baseline. It does not
predict DOAJ's decision. DOAJ editors review the official application.
The editor can apply at https://doaj.org/apply/ after reviewing the
findings. If required items remain unresolved, show them before the link.
