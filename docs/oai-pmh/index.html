User Guide

Follow these steps to inspect and analyze the journal's OAI-PMH service:

  • 1Enter the journal homepage URL (e.g. https://jurnal.unand.ac.id/index.php/jidt) or direct OAI endpoint.
  • 2Click the Validate OAI-PMH button to launch automated discovery.
  • 3The system discovers the endpoint, checks XML Identify validity, and inspects harvest readiness.
  • 4Review harvestability status, metadata quality scores, and actionable recommendations.
This application runs directly on GitHub Pages and only reads public metadata from the OAI-PMH endpoint. No OJS login required. A built-in public CORS proxy layer allows browsers to read OAI-PMH XML directly from journal servers.
