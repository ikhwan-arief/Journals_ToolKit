User Guide

  1. Copy the journal website URL (e.g., https://jurnal.unand.ac.id/index.php/jidt).
  2. Paste into the text area. You can input up to 10 URLs (one URL per line).
  3. Click the Check OJS Version & OAI-PMH button.
  4. Review the OJS lifecycle status, server PHP compatibility, upgrade pathway recommendations, and OAI-PMH endpoint availability.
  5. If any URL is protected by a strict campus CORS/WAF, use the Manual Input button in the details card to paste the generator meta line instantly.
